# دليل التشغيل والنشر

## 1. المتطلبات المسبقة
- Python 3.12 أو أحدث
- متغيرات البيئة المشار إليها في `.env.example` (توكن البوت، مفاتيح TON، معرّفات المشرفين...إلخ)
- قاعدة بيانات SQLite (يتم إنشاؤها تلقائيًا عند التشغيل)

## 2. تثبيت الاعتمادات
```bash
pip install -r requirements.txt
```

## 3. تشغيل البوت
```bash
APP_ENV=prod python bot.py
```
- عند التشغيل يتم تهيئة خدمات الأسعار والرصيد، بالإضافة إلى مخزن الحالة المعتمد على قاعدة البيانات.
- استخدم الأمر `/admin` من حساب مشرف لرؤية لوحة المراقبة (الرصيد، الأسعار، آخر الأخطاء، عدّادات المقاييس).

## 4. مراقبة وتشخيص
- لوحة `/admin` تُظهر حالة المهام الخلفية (`BalanceMonitor`, `PricingService`) وآخر الأخطاء.
- في حال فشل تحويل TON يتم تسجيل الحدث في المقاييس (`ton_transfer_failed`) ليظهر في لوحة المشرف.
- سجلات التشغيل تُكتب في `logs/` (مُهملة من نظام التحكم بالإصدارات).

## 5. الاختبارات والجودة
- شغّل الاختبارات قبل أي نشر:
```bash
pytest
```
- الاختبارات تشمل الوحدات (مثل `MetricsCollector`) والتكامل البسيط (تخزين FSM، مراقبة الرصيد).
- يتم تنفيذ نفس الاختبارات تلقائيًا عبر GitHub Actions (`.github/workflows/tests.yml`).

## 6. التحديث والصيانة
- عند تعديل الأسعار أو مفاتيح API قم فقط بتغيير متغيرات البيئة ثم إعادة تشغيل الخدمة.
- في حالات الطوارئ (تعطل خدمة TON مثلًا):
  1. راجع `/admin` للتحقق من عدّادات الأخطاء.
  2. أوقف الخدمة بأمان (Ctrl+C) ثم أعد تشغيلها بعد معالجة السبب.
  3. تتبع آخر المعاملات من قاعدة البيانات (`completed_transactions`) للتحقق من الوضع المالي للمستخدمين.

## 7. أدوار المشرفين
- `ADMIN_USER_IDS` في ملف البيئة تحدد حسابات تيليغرام المسموح لها باستخدام `/admin`.
- أضف أو أزل المعرّفات (مفصولة بفواصل) ثم أعد تشغيل البوت لتطبيق التغيير.
